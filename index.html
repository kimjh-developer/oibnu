소프트웨어 제작 · 유지보수

필요한 소프트웨어를 만들고,
만든 뒤에도 곁에 있습니다.

오이비누는 작은 회사와 팀이 실제로 쓰는 웹 서비스, 앱, 업무 도구를 설계하고 개발합니다. 출시로 끝내지 않고, 고치고 지키는 일까지 맡습니다.

프로젝트 문의하기 하는 일 보기

하는 일

두 가지를 합니다.
만드는 일, 그리고 지키는 일.

01

만들기 Build

지금 손으로, 엑셀로, 메신저로 하던 일을 소프트웨어로 옮깁니다. 꼭 필요한 기능부터 작게 시작합니다.

  • 웹 서비스와 관리자 페이지
  • 모바일 앱 (Android · iOS)
  • 사내 업무 도구와 자동화
  • 결제 · 메신저 · 외부 API 연동

02

지키기 Maintain

소프트웨어는 출시한 날부터 손이 갑니다. 운영 중인 서비스를 맡아 오래 안정적으로 돌아가게 관리합니다.

  • 버그 수정과 기능 개선
  • 서버 · 배포 운영과 장애 대응
  • 보안 업데이트와 라이브러리 관리
  • 백업과 복구 절차 점검

일하는 방식

문서로 합의하고,
동작하는 화면으로 보여드립니다.

  1. 1

    듣기

    지금 일하는 방식과 불편한 지점을 먼저 듣습니다. 무엇을 만들지보다 왜 필요한지부터 정리합니다.

  2. 2

    범위 정하기

    꼭 필요한 기능, 일정, 비용을 문서로 합의합니다. 나중에 해도 되는 일은 따로 적어 둡니다.

  3. 3

    만들기

    짧은 주기로 실제 동작하는 화면을 공유하며 개발합니다. 중간에 방향을 바로잡을 수 있습니다.

  4. 4

    넘겨주고 지키기

    소스코드와 운영 문서를 함께 전달하고, 원하시면 유지보수로 이어서 관리합니다.

직접 만드는 제품

오이비누 사내 메신저

10~50인 회사를 위한 설치형 사내 메신저입니다. 회사 PC 한 대가 채팅 서버가 되어, 대화 기록이 회사 안에 저장됩니다.

현재 개발 중

  • Windows PC 한 대로 설치별도 서버나 클라우드 계약 없이 시작합니다.
  • 사내망에서 브라우저로 접속직원은 같은 네트워크에서 바로 들어옵니다.
  • 1:1 대화와 단체방초대, 퇴장, 방장 변경 같은 기본 기능을 갖춥니다.

문의하기

한두 줄이면 충분합니다.
